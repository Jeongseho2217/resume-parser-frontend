# git Rule
- **Main**: 완성품이 올라갈 브랜치, **절대 Main 브랜치에 직접 푸시 금지!**
- **Develop**: Feature의 결과 중 팀원간 코드 리뷰 후 병합할 브랜치
- **Feature/(기능 이름)**: 개인 작업 공간. 실수해도 자르고 다시 만들 수 있음. 작업이 완료 될 경우 **Develop로 PR 날려주세요!**
  - 예시) `Feature/Login-api`
